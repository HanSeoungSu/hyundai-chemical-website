- 가성소다·수산화나트륨(동일 물질), 구연산, KOH·수산화칼륨의 한글·영문 상세페이지 추가. 제품 목록에서 각각 연결하고 한글명·영문명·CAS 번호 검색 지원
- 공급처명, 제조사별 규격·포장·순도·재고·가격을 노출하거나 단정하지 않음. 구연산은 무수구연산·함수구연산(일수화물)의 CAS 번호를 구분하여 표시하고 실제 공급 형태는 문의로 확인
- 사용자 확인에 따라 제품목록의 수산을 `수산(함수)`로 표기하고 CAS No. 6153-56-6 연결. 이수화물이라는 명칭은 화면에 표시하지 않으며, 옥살산·영문명·CAS 번호 검색을 지원
- 사용자가 고른 생성 사진 2장만 사용: 알칼리 플레이크 예시 이미지는 가성소다와 KOH에 공용, 흰 결정 예시 이미지는 구연산에 사용. 실제 공급 제품 사진이 아닌 참고 이미지임을 본문에 표기
- 상세페이지의 견적·MSDS 요청은 기존 문의 흐름으로 연결. 정적 한영 페이지, canonical·hreflang·사이트맵, 제품 구조화 데이터 추가. 자료 근거는 `docs/cas-catalog-sources.md` 참조
- 국문·영문 모두 CAS별 PubChem 물질정보 페이지로 바로 연결. 출처는 실제 납품 제품의 MSDS나 제조·공급처가 아님을 명시하고, 실제 MSDS는 요청 후 제품 확인 절차 유지

## 시약 상세페이지 (2026-09-30)
- 시약 중 증류수 4L 1개와 메탄올 4개 제품을 물질별 상세페이지 2개에 연결. 제조 시약은 이번 범위에서 제외
- 물질 CAS No.는 각각 물 7732-18-5, 메탄올 67-56-1이며 기존 `data/cas-catalog.json`의 검증된 값을 사용. 이 번호로 제조사별 등급·순도·규격을 단정하지 않음
- 상세페이지에 등록 제품별 견적 및 MSDS 요청 링크, 한영 페이지와 사이트맵 항목 추가. 덕산 제품의 공개 참고 링크는 덕산약품 공식 제품정보로 교체. 실제 제품 MSDS는 요청 후 확인
- 덕산 증류수 4L와 메탄올 4L는 HPLC 등급, 메탄올 500mL는 EP(Extra Pure) 등급으로 표기. 정확한 제품번호·세부 사양은 제품 자료로 확인. 확인된 동일 제품 사진이 없어 상세페이지에는 제품 사진을 넣지 않음

- 모바일 검증에 320/390px 한글·영문 로고의 메뉴 간격 및 자동 다크 모드 전후 상단 스크린샷 동일성 검사 추가
- `node --test tests/mobile-logo.test.cjs`: 배경/원 내부 투명도, 오른쪽 수평 절개, 왼쪽 원 유지, N 색상 및 16개 페이지의 공통 PNG 연결 검사 (`pngjs` 필요). 실제 휴대폰 브라우저의 강제 색상 변경은 별도 기기 확인 대상

## 제품 탐색·납품 문의 개선 (2026-09-30)
- 제품명 검색 시 기존 분류 선택을 해제하고 4개 분류 전체에서 검색. 분류는 재클릭하거나 `분류 선택 해제` 버튼으로 해제 가능
- 모든 카탈로그 제품 카드의 문의 링크가 제품명을 견적 양식에 전달하며, 검색 결과가 없을 때도 검색어를 담아 문의 가능
- 제품 검색 영역을 모바일 첫 화면에서 더 빨리 볼 수 있도록 제품 페이지 상단을 압축
- 홈의 기존 주 문구를 유지하고 약속한 납기일 준수와 신속한 납품을 설명에 추가. 울산항·온산항·부산항 중심 공급은 회사소개 본문에 안내
- 견적 양식에 선택형 수량, 납품 항만·지역, 희망일을 추가. 긴급 납품 전용 버튼·문의 구분·메일 제목 표시는 두지 않음
- 사업분야 하단에 취급 제품·견적 문의로 이동하는 일반 안내 추가
- 영문 페이지는 `node scripts/build-locales.mjs`로 재생성하고, 견적 API 단위 테스트를 추가
- 견적·MSDS 실제 메일 실발송은 배포 후 별도 확인 필요

언어별 주소와 공통 파일을 함께 확인하려면 프로젝트 폴더에서 미리보기 서버를 실행합니다:

```bash
python preview-server.py --port 8080
```

브라우저에서 `http://localhost:8080/` 또는 `http://localhost:8080/en/` 접속. 로컬 정적 미리보기에서는 메일이 발송되지 않습니다.

## 사내 네트워크 공유 미리보기

프로젝트 폴더의 `start-lan-preview.cmd`를 더블클릭하면 같은 사내 네트워크에서 접속 가능한 주소가 표시됩니다.

PowerShell에서 직접 실행하려면:

```powershell
.\start-lan-preview.ps1
```

표시 예시:

```text
사내 접속: http://192.168.0.8:8080/
컴퓨터 이름으로 접속: http://HDCHEM4:8080/
```

- 미리보기 창을 실행한 컴퓨터와 접속자가 같은 사내 네트워크에 있어야 합니다.
- 미리보기 창과 컴퓨터가 켜져 있어야 접속할 수 있습니다.
- 미리보기 서버는 수정된 HTML·CSS·JavaScript가 즉시 반영되도록 브라우저 캐시를 비활성화합니다.
- IP 주소는 네트워크 설정에 따라 바뀔 수 있으므로 실행 창에 표시된 최신 주소를 사용합니다.
- Windows 방화벽 요청이 나타나면 회사 IT 정책을 확인하고 개인 네트워크만 허용합니다.
