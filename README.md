- 폼 입력 글자 16px, 날짜 입력 폭 제한, 가로 화면 메뉴의 내부 스크롤 적용
- `node tests/mobile-layout.test.cjs`: 한글·영문 16페이지를 320/360/390/430/600/768/900px에서 검사. 제품 분류·작업사진 펼침, 130% 글자 크기, 가로 화면 메뉴 포함
- 문서 전체 폭뿐 아니라 `overflow:hidden` 내부의 실제 텍스트 잘림 및 홈 구성요소 배치도 검사. 테스트는 로컬 정적 서버를 사용하며 메일을 발송하지 않음

## 모바일 로고 가독성 보완 (2026-09-29)
- 900px 이하에서는 원본처럼 파란 원을 가로지르는 `HYUNDAI CHEMICAL` 로고 사용. 왼쪽 원은 이어지고, 오른쪽은 실제 글자 높이(14 SVG 단위)만큼 수평으로 절개. 흰 글자와 어두운 `N`을 유지하며 데스크톱 원본 로고 파일은 보존
- 모바일 배포 이미지는 투명 배경의 1040×352 PNG로 고정해 휴대폰의 SVG 글자 폰트 대체 및 개별 요소 색상 변환을 피함. 원본 SVG도 사각 배경/덧칠 대신 실제 투명 절개를 사용. `node scripts/build-mobile-logo.cjs`로 Arial이 설치된 제작 환경에서 재생성하며 Playwright/Chromium 필요. 한글·영문 페이지가 같은 PNG를 사용
- 모바일 상단 배경을 불투명 남색으로 고정하고 `color-scheme: only light` 및 동일 meta 태그로 브라우저 자동 다크 변환에 의한 색상 왜곡 방지 ([Chrome 공식 안내](https://developer.chrome.com/blog/auto-dark-theme#how_to_opt-out_of_auto_dark_theme)). 강제 색상 변경 기능은 브라우저별 차이가 있을 수 있음
- 모바일 검증에 320/390px 한글·영문 로고의 메뉴 간격 및 자동 다크 모드 전후 상단 스크린샷 동일성 검사 추가
- `node --test tests/mobile-logo.test.cjs`: 배경/원 내부 투명도, 오른쪽 수평 절개, 왼쪽 원 유지, N 색상 및 16개 페이지의 공통 PNG 연결 검사 (`pngjs` 필요). 실제 휴대폰 브라우저의 강제 색상 변경은 별도 기기 확인 대상

## 네이버 지도 연동
- 회사소개 하단에 오시는 길, 주소, 대표전화, 영업시간 및 네이버 지도 연결 영역 적용
- `company.html`의 `data-ncp-key-id`에 네이버 클라우드 Web Dynamic Map Client ID를 입력하면 지도가 활성화됨
- Web 서비스 URL에는 현재 미리보기 주소와 추후 사용할 정식 도메인을 등록
- Client ID만 웹페이지에 사용하며 Client Secret은 저장소 또는 HTML에 입력하지 않음

## 페이지 구조
- `index.html`: 홈
- `company.html`: 회사소개

## 로컬 실행
언어별 주소와 공통 파일을 함께 확인하려면 프로젝트 폴더에서 미리보기 서버를 실행합니다:

```bash
python preview-server.py --port 8080
```

브라우저에서 `http://localhost:8080/` 또는 `http://localhost:8080/en/` 접속. 로컬 정적 미리보기에서는 메일이 발송되지 않습니다.

검증: `node --test tests/msds-api.test.mjs`, Playwright 설치 환경에서 `node tests/site-browser.test.cjs`. 브라우저 검증은 요청을 가로채어 테스트하므로 실제 메일을 발송하지 않습니다.

## 사내 네트워크 공유 미리보기

프로젝트 폴더의 `start-lan-preview.cmd`를 더블클릭하면 같은 사내 네트워크에서 접속 가능한 주소가 표시됩니다.

PowerShell에서 직접 실행하려면:

```powershell
.\start-lan-preview.ps1
```

표시 예시:

```text
사내 접속: http://192.168.0.8:8080/
컴퓨터 이름으로 접속: http://HDCHEM4:8080/
```

- 미리보기 창을 실행한 컴퓨터와 접속자가 같은 사내 네트워크에 있어야 합니다.
- 미리보기 창과 컴퓨터가 켜져 있어야 접속할 수 있습니다.
- 미리보기 서버는 수정된 HTML·CSS·JavaScript가 즉시 반영되도록 브라우저 캐시를 비활성화합니다.
- IP 주소는 네트워크 설정에 따라 바뀔 수 있으므로 실행 창에 표시된 최신 주소를 사용합니다.
- Windows 방화벽 요청이 나타나면 회사 IT 정책을 확인하고 개인 네트워크만 허용합니다.
- 외부 인터넷 공개용이 아니며, 정식 공유가 필요하면 Cloudflare Pages 배포를 사용합니다.
