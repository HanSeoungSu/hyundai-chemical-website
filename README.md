# 현대케미칼(주) 공식 홈페이지

현대케미칼(주) 기업 홈페이지 프로젝트입니다.

## v0.1 목표
- 현대케미칼 브랜드 기반 반응형 메인페이지
- 회사소개 / 사업분야 / 제품소개 / 선용품 / 견적문의 UI
- PC / 모바일 대응
- 별도 프레임워크 없이 정적 배포 가능
- 향후 Cloudflare Pages 배포를 전제로 단순한 구조 유지

## 현재 반영 정보
- 회사명: 현대케미칼(주)
- 주요 사업: 선박 선용품 납품, 신나·용제 소분 판매
- 대표 품목: 톨루엔, 자일렌, 메탄올, 에나멜(솔벤트), 에폭시 신나, 락카 신나, 우레탄 신나, 차아염소산나트륨, 가성소다
- 주력 제품: HC-2700, MC, HC-2750
- 기타 유기·무기 화합물 다수 취급

## 로컬 실행
가장 간단하게 `index.html`을 브라우저에서 열어도 됩니다.

로컬 서버를 사용한다면 프로젝트 폴더에서:

```bash
python -m http.server 8080
```

그 다음 브라우저에서 `http://localhost:8080` 접속.
