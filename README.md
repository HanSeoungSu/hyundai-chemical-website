## 제품 카탈로그 구조
- 제품명 검색 기능
- 첫 진입 시 대분류 선택 안내 표시
- 실험실 기자재 / 유·무기 화합물 / 선용품기자재 / 신나류 대분류
- 기존 공급 형태와 품목 종류를 활용한 `대분류 → 중분류 → 제품` 단계형 탐색
- 시약은 증류수 / 메탄올 세부 분류를 거쳐 용량·제조사별 제품이 펼쳐지는 4단계 탐색 적용
- 샘플병 200ml / 500ml는 시약에서 실험실 기자재 중분류로 이동
- 실험실 기구·소모품은 측정·분석기구 / 채취·분주용품 / 용기·보관용품 / 기타의 4개 소분류로 구성
- 실험실 기구·소모품의 STEP 04에서는 여러 규격이 있는 제품군만 선택 버튼으로 표시하고, 1개뿐인 단일 제품은 제품 카드를 바로 표시
- 같은 제품류의 규격은 숫자와 단위를 환산해 작은 순서로 표시하고, 서로 다른 제품명과 제품 종류는 가나다·ABC 순으로 정렬
- NESSLER TUBE RACK 2종은 측정·분석기구의 NESSLER TUBE 제품군에 포함
- FUNNEL은 기타 소분류의 단일 제품으로 표시하고, VOLUMETRIC FLASK / TUBE BRUSH / THERMOMETER는 측정·분석기구의 개별 제품 종류로 표시
- FILTER PAPER와 TEST PAPER는 측정·분석기구의 개별 제품 종류로 표시하고, 여과·시험용품 소분류는 사용하지 않음
- ICE BOX와 PEN RIGHT는 기타 소분류에 포함하며, 이동 후 비어 있는 용기·보관용품의 기타 제품군은 표시하지 않음
- PIPETTE FILLER는 채취·분주용품에서 기타 소분류로 이동
- 유·무기 화합물의 `(세척제) 퐁퐁`은 `퐁퐁`으로 표시
- 제조 시약 목록에 질산 20% 포함
- 유·무기 화합물은 드럼 / 탱크 용제 / 말통 / 고체 중분류로 구성하며 IBC와 고체·액체 중분류는 사용하지 않음
- 차아염소산나트륨과 가성소다는 드럼·말통에 표시하고, 가성소다는 고체에도 표시
- 드럼 제품에 MEK / 암모니아 / EA / DOP / 클로로포롬을 포함하고 HC-2750으로 표기
- 탱크 용제의 솔벤트 단독 품목은 제외하고 신나류의 에나멜신나는 `에나멜신나(솔벤트)`로 표기

## 로컬 실행
가장 간단하게 `index.html`을 브라우저에서 열어도 됩니다.

로컬 서버를 사용한다면 프로젝트 폴더에서:

```bash
python -m http.server 8080
```

그 다음 브라우저에서 `http://localhost:8080` 접속.

## 사내 네트워크 공유 미리보기

프로젝트 폴더의 `start-lan-preview.cmd`를 더블클릭하면 같은 사내 네트워크에서 접속 가능한 주소가 표시됩니다.

PowerShell에서 직접 실행하려면:

```powershell
.\start-lan-preview.ps1
```

표시 예시:

```text
사내 접속: http://192.168.0.8:8080/
컴퓨터 이름으로 접속: http://HDCHEM4:8080/
```

- 미리보기 창을 실행한 컴퓨터와 접속자가 같은 사내 네트워크에 있어야 합니다.
- 미리보기 창과 컴퓨터가 켜져 있어야 접속할 수 있습니다.
- 미리보기 서버는 수정된 HTML·CSS·JavaScript가 즉시 반영되도록 브라우저 캐시를 비활성화합니다.
- IP 주소는 네트워크 설정에 따라 바뀔 수 있으므로 실행 창에 표시된 최신 주소를 사용합니다.
- Windows 방화벽 요청이 나타나면 회사 IT 정책을 확인하고 개인 네트워크만 허용합니다.
- 외부 인터넷 공개용이 아니며, 정식 공유가 필요하면 Cloudflare Pages 배포를 사용합니다.
